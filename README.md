# منصة م. يوسف طارق للرياضيات

باك إند Node.js حقيقي (بدون أي مكتبات) + واجهة SPA.

## التشغيل
    node server.js            # يتطلب Node 18+
    ADMIN_PHONE=01xxxxxxxxx ADMIN_PASS=كلمة_قوية PORT=3000 node server.js
افتح http://localhost:3000 — الأدمن الافتراضي: `admin` / `admin123` (غيّره قبل النشر!)
اختبار الباك إند: `node test.js` (والسيرفر شغال).

## النشر
أي VPS أو Render / Railway / Fly.io: شغّل `node server.js` وخلّي مجلد `data/` على تخزين دائم (Volume).
ضع Nginx أو Cloudflare أمامه مع HTTPS. لا تشارك ملف `data/.secret`.

## اللي في الباك إند
- تشفير كلمات السر (scrypt) وتوكن موقّع HMAC مدته 30 يوم، وحد لمحاولات الدخول.
- قفل الجهاز الواحد على السيرفر (الأدمن يفك الارتباط من لوحة الطلاب).
- فتح الحصص بالترتيب يتحقق منه السيرفر، والإجابات الصحيحة لا تصل للمتصفح قبل التسليم.
- تصحيح تلقائي، ورفض التسليم لو في أسئلة بدون إجابة.
- رفع صور، رسائل دعم فني، إحصائيات، أمان headers + CSP.

## ملاحظات
- التخزين ملف JSON بكتابة ذرّية: ممتاز لمئات/آلاف الطلاب. لو المنصة كبرت جداً انقلها لـ PostgreSQL.
- الفيديو بيتحمّل من YouTube (Unlisted) أو Vimeo أو mp4. للحماية الأقوى استخدم Bunny Stream / Vimeo مع تقييد الدومين.
- قفل الجهاز مبني على معرّف محفوظ في المتصفح، فمسح بيانات المتصفح يحتاج فك ارتباط من الأدمن.
- العلامة المائية فوق الفيديو ردع قوي، لكن لا توجد حماية مطلقة ضد تصوير الشاشة.

## تحديثات الواجب والامتحان والشرح
- **صفحة الواجب/الامتحان** (`#/exam/:lesson/:h|q`): عدّاد أحمر، كارت فيديو شرح التسليم، زر إنهاء الاختبار، استكمال لاحقًا (بيحفظ الإجابات على السيرفر)، إحصائيات لحظية، ترقيم الأسئلة، درجة السؤال، القسم، صورة السؤال مع تكبير.
- **زر الإنهاء**: لو في أسئلة ناقصة تظهر رسالة "الأسئلة غير مكتملة" (النص قابل للتعديل من المظهر ← النصوص)، ولو كله محلول تظهر نافذة: تسليم أو مراجعة سريعة للإجابات.
- **انتهاء الوقت**: لو الطالب خرج والوقت خلص، السيرفر بيصحح تلقائيًا من آخر إجابات محفوظة.
- **الشرح**: قائمة فيديوهات وملفات (PDF أو صور) بعناوين، الأدمن بيضيف منها أي عدد، والرفع من الجهاز متاح (PDF حتى 100MB، `MAX_FILE_MB` لتغييره).
- **الأسئلة**: منشئ مرئي بدل الصيغة النصية، اختيارات حروف (أ ب ج د) أو نصوص، درجة وقسم لكل سؤال، ورفع عدة صور دفعة واحدة (كل صورة = سؤال، وتتضغط تلقائيًا).
- **الفوتر**: أيقونات فيسبوك/انستجرام/تيك توك/يوتيوب (الأدمن يضيف الروابط من الإعدادات، والفاضي لا يظهر) + سطر Developed by Daniel + رقم واتساب (عدّل DEV في index.html). غيّر رقمك من الثابت `DEV` في أول سكربت `public/index.html`.
- **فيديو شرح التسليم**: يتحدد من الإعدادات (اختياري).

## أوائل الثانوية
قسم اختياري في الصفحة الرئيسية. من لوحة الأدمن ← تبويب "🏆 أوائل الثانوية": أضف الطلاب (الاسم، الدرجة، السنة، صورة اختيارية) واستخدم الـ checkbox لإظهار/إخفاء القسم. لو مفيش أسماء القسم مش بيظهر.

## ألوان عناصر الهيرو
من لوحة الأدمن ← "🎨 المظهر والأيقونات" ← كارت "✨ ألوان عناصر صورة المدرس": لون المثلث، الإطار الذهبي، π، الكشكول، الكور، المنقلة (+ زر رجوع للألوان الأصلية).

## أوائل الثانوية العامة (تحديث)
كل طالب: القسم (عنوان المجموعة)، الاسم، الشارة، المجموع الكلي، سطر إضافي، المحافظة، الشعبة، صورة اختيارية. الطلاب بنفس القسم بيتجمّعوا تحت عنوان واحد والترتيب #1 #2 بحسب ترتيبهم.

## تحديث: الصورة واللودر وشارة الاشتراك
- **صورة المدرس**: `public/assets/teacher.png` بخلفية شفافة وتلاشي ناعم من تحت (مفيش حد حاد)، مع قناع CSS إضافي في الهيرو.
- **لودر هولوجرام**: آلة حاسبة خطوط فقط (فاضية) بتترسم وتكتمل، بيظهر داخل المنصة عند فتح الكورسات / صفحة الكورس / الحصة (مش عند أول فتح الموقع). التعديل في `#hl` داخل `public/index.html`، ومدة العرض الأدنى (1450ms) في متغير `rd` داخل `route()`.
- **مشترك بالفعل**: شريط أخضر على جنب كارت الكورس + زر "ادخل الكورس" بدل "اشترك الآن" (للكورسات المدفوعة اللي الطالب مفعّلها). وبيتحدث تلقائيًا لما الأدمن يفعّل الاشتراك.

## بيانات الطالب، تعليمات التسجيل، المشاهدات، رسالة ولي الأمر
- **التسجيل**: رقم الطالب، رقم ولي الأمر، المحافظة (كل المحافظات)، المدرسة، السنة الدراسية (3 إعدادي / 1 ثانوي / 2 بكالوريا / 3 ثانوي). الطلاب القدام بتظهرلهم نافذة تكمّل البيانات. الطالب مبيقدرش يعدّل بياناته بعد الحفظ، الأدمن بس (الطلاب > بيانات).
- **التعليمات قبل التسجيل**: نافذة "تعليمات هامة" بتظهر أول ما الطالب يفتح صفحة إنشاء الحساب. النص يتعدل من لوحة التحكم (ولي الأمر والتعليمات) وممكن تتقفل.
- **حد المشاهدات**: في تعديل الكورس، حقل "عدد المشاهدات" لكل حصة، وزر لتطبيق رقم واحد على كل الحصص (0 = بلا حد). الدخول المتكرر للحصة خلال ساعتين بيتحسب مشاهدة واحدة (غيّره بالمتغير `VIEW_WINDOW_MIN`). لما المشاهدات تخلص بتختفي فيديوهات الحصة وتفضل الملفات والواجب والامتحان. الأدمن يزوّد مشاهدة أو يصفّر من الطلاب > المشاهدات.
- **رسالة ولي الأمر**: بتتسجل مع كل مشاهدة محسوبة وتظهر في لوحة التحكم > ولي الأمر والتعليمات ومعاها زر واتساب جاهز. للإرسال التلقائي بالكامل لازم بوابة واتساب/SMS خارجية: اضبط `NOTIFY_URL` (والتوكن اختياري في `NOTIFY_TOKEN`) والسيرفر هيعمل POST بصيغة JSON فيها `to` (الرقم بالصيغة الدولية) و`text`.
